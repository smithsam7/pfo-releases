# PFO · Peak Financial Outlook

Installers for PFO, a household net worth and goals tracker that runs on your own computer.

This repository holds releases only: no source code, and never anyone's data.

## Install

Download the latest version from [Releases](https://github.com/smithsam7/pfo-releases/releases):

- **Mac:** the `.dmg` file. Open it and drag PFO to Applications.
- **Windows:** the `.exe` file. Windows may warn that the app is from an unknown publisher; choose **More info → Run anyway**.

No releases yet: the first test builds are on the way.

## Your data

Everything you enter stays in a file on your computer. Nothing is sent anywhere, and nobody else, including whoever made the app, can see it. PFO does not encrypt that file, so turn on disk encryption (FileVault on a Mac, BitLocker on Windows) and keep the backups you make from Settings somewhere private.
